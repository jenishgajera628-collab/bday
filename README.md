# Build a Premium Romantic Birthday Surprise Website – "Our Little Universe"

Act as a world-class UI/UX designer and senior frontend developer. Create a beautiful, premium, cinematic, romantic birthday surprise website for my girlfriend, Yuku.

IMPORTANT: This is a FRONTEND-ONLY project. Focus entirely on UI design, animations, visual storytelling, responsive layouts and interactive frontend experiences.

Do NOT build any backend, database, authentication, API integrations, payment systems or admin panel. Do not use paid services. Use placeholder images that can be replaced with our real couple photos later.

## 1. Overall Design Direction

Create a unique combination of:
- Dark luxury romantic aesthetics.
- Soft pink and burgundy accents.
- Vintage scrapbook and Polaroid memories.
- Cinematic transitions.
- Cute floating hearts, stars, sparkles and subtle animations.

The website should feel like a premium romantic experience, not a generic birthday template.

Color palette:
- Deep black: #0B080D
- Burgundy: #5B1837
- Rose pink: #F3A6BD
- Soft blush: #FCE4EC
- Champagne gold: #D9B879
- Cream: #FFF5EB

Use elegant typography, beautiful spacing, soft glows, glassmorphism and subtle gradients.

## 12. Technical Requirements

- Use React.
- Use Tailwind CSS.
- Use Framer Motion if available.
- Use Lucide icons.
- Build clean, reusable components.
- Keep all text, photos, dates and memories easy to customize.
- Use placeholder image assets.
- Make every interactive element functional on the frontend.
- No backend.
- No database.
- No authentication.
- No paid integrations.
- No unnecessary external APIs.

## 13. Responsive Design

The website MUST look beautiful on:
- Mobile phones.
- Tablets.
- Desktop screens.

Mobile-first design is extremely important.

Make the photo gallery, timeline, animations and letter sections perfectly responsive.

## FINAL DESIGN INSTRUCTION

The final result should feel like a premium romantic digital scrapbook mixed with a cinematic birthday experience.

Do not make it look like a normal business website.

Avoid generic templates, excessive boxes, boring layouts and oversized empty spaces.

Prioritize emotional storytelling, beautiful typography, elegant transitions and memorable visual details.

Build the entire frontend in one consistent design system.
